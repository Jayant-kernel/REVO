# Objections (handled with evidence, not slogans)

**"Synthetic data is low quality."**
FACT: ours is execution-verified per record with mutation-scored
suites — inspect any Golden record's verification evidence. MEASURED
model lift: none yet; run the pilot.

**"Your benchmark is contaminated."**
Process, not promise: private benchmarks are frozen, fingerprinted,
and contamination-checked across exact/structural/semantic/template/
membership categories before any experiment. Reports included.

**"We can generate our own synthetic data."**
Probably. The control arm exists for exactly this: generic synthetic
vs verified synthetic on your benchmark. If verification adds
nothing, the experiment will say `HYPOTHESIS_NOT_SUPPORTED` and we
will report it.

**"Too expensive / unknown ROI."**
UNKNOWN until measured: pilot success criteria include economics
(inputs recorded, assumptions labeled). No price is quoted as fact
before customer evidence.

**"Compliance / data provenance?"**
FACT: content-addressed lineage per record, dataset snapshots,
reproduction manifests, license records per model. Secrets are never
captured; exports are redacted and scrubbed.
