# Business Validation — Verified SQL Data Factory

Status: **Phase 0 — plan only. No outreach, pilots, or sales activity yet.**

## Validation sequence

```text
Build sample
    ↓
Publish public sample
    ↓
Build private benchmark
    ↓
Evaluate existing models
    ↓
Train/fine-tune experiment
    ↓
Measure improvement on unseen tasks
    ↓
Create case study
    ↓
Contact AI startups
    ↓
Offer free evaluation pilot
    ↓
Sell training/evaluation data
```

## Notes per step

- **Sample before scale:** a small public sample tests whether anyone cares
  before investing in 100k-record production.
- **Private benchmark:** held-out tasks that never ship publicly; the antidote
  to contamination and the core of the eval-pilot offer.
- **Train/fine-tune experiment:** the commercial proof — does verified data
  improve an agent on *unseen* tasks? Without this, there is no case study.
- **Pilots before sales:** free evaluation pilots with a narrow success metric
  agreed upfront; convert only on measured improvement.
