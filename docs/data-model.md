# Data Model (conceptual) — Verified SQL Data Factory

Status: **Phase 0 — design document only. No database implementation.**

## Entities (minimum set)

```text
Task, TaskVersion, TaskTemplate, Fixture,
CandidateSolution, VerificationRun, TestSuite, TestCase,
MutationRun, QualityReport, FailureEvent,
Dataset, DatasetVersion,
ModelVersion, OracleVersion, ContainerImage, LicenseRecord
```

## Relationships

```text
Task
 └── TaskVersion
      ├── Fixture
      ├── OracleVersion
      ├── TestSuite
      └── CandidateSolution
             └── VerificationRun

Dataset
 └── DatasetVersion
       └── TaskVersion
```

## Entity notes

- **Task** — stable identity for a problem family instance (e.g. "funnel analysis #17").
  Owns difficulty, family, and lifecycle state.
- **TaskVersion** — immutable snapshot: instruction text + schema + template
  version + fixture seed + oracle/test-suite versions it was verified against.
  Re-running with the same versions + seed must reproduce the same fixture
  and verdict.
- **TaskTemplate** — parameterized generator for a family (e.g. window-function
  template with difficulty knobs). Versioned; referenced by TaskVersion.
- **Fixture** — deterministic dataset (tables + rows + seed) the SQL runs against.
  Generated by seeded code, never hand-edited after versioning.
- **CandidateSolution** — one model output for one TaskVersion (normalized SQL text
  + parser metadata + model/prompt references).
- **TestSuite / TestCase** — the executable checks for a TaskVersion:
  public tests, hidden tests, property tests, metamorphic checks.
  Versioned as a unit.
- **VerificationRun** — one execution of a CandidateSolution against a
  TestSuite in a pinned ContainerImage: per-test results, timing, oracle
  comparison, final verdict.
- **MutationRun** — mutation-testing assessment of a TestSuite's strength
  (mutants killed / survived → mutation score).
- **QualityReport** — post-verification assessment: duplicates, coverage,
  difficulty fit, ambiguity flags, human-audit outcome.
- **FailureEvent** — structured record of informative failures (wrong answer,
  timeout, parse failure, oracle disagreement) for failure datasets + debugging.
- **ModelVersion** — model id + revision + serving config + license reference.
- **OracleVersion** — reference-solution logic + version (independent of candidate).
- **ContainerImage** — sandbox image digest + dependency pin list.
- **Dataset / DatasetVersion** — curated set of TaskVersions (+ their verified
  solutions, verification evidence, quality reports) frozen for training,
  eval, preference, or failure use.
- **LicenseRecord** — license/terms evidence for every model, dataset, code,
  and source material used (see `docs/licensing.md`).

## Invariants (to be enforced in implementation)

1. TaskVersion, TestSuite, Fixture, VerificationRun are immutable once created.
2. A DatasetVersion references exact TaskVersion ids — never floating "latest".
3. Every CandidateSolution links to exactly one TaskVersion + one ModelVersion.
4. Every VerificationRun links to one CandidateSolution + one TestSuite version
   + one ContainerImage digest.
5. Commercial export (Phase 7) requires a QualityReport + LicenseRecord chain.
